# PMD — New Mobile Prototype

This is a fresh, independent visual prototype based on the PMD PRD. It does not reuse the previous screen designs.

## Open
Open `index.html` in a modern browser.

## Prototype interactions
- Navigation across Home, Tasks, Projects, Calendar, Education, People, and More
- Light/dark toggle (white and black base themes)
- Create/edit tasks
- Complete tasks
- Task filters and search
- Create/edit projects
- Open project workspace and linked-task display
- Create/edit people records and view profile information
- Education overview structure
- Responsive mobile bottom navigation

## Prototype limitations
This is a front-end prototype with in-memory sample records. Records are not persisted after refreshing. Some modules are screen placeholders for later implementation, including AI, vault security, settings, detailed academic workflows, and full calendar event management. Do not enter sensitive information.

## Design direction
Clean white light theme, black dark theme, restrained accent color, mobile-first navigation, fresh screen compositions.
